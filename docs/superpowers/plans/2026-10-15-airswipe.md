# AirSwipe Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A small macOS tool that turns air swipes and hand height into back/forward and scrolling, using only the built-in camera.

**Architecture:** A pure, unit-tested gesture state machine (`AirSwipeCore`) sits between a thin Vision/AVFoundation front end and a thin CGEvent back end (`airswipe`). All timing comes from sample timestamps, so tests need no camera and no real clock.

**Tech Stack:** Swift 6.1 (language mode 5), SwiftPM, AVFoundation, Vision (`VNDetectHumanHandPoseRequest`), CoreGraphics `CGEvent`, AppKit `NSStatusItem`, Swift Testing.

**Spec:** `docs/superpowers/specs/2026-10-15-airswipe-design.md`

## Global Constraints

- macOS 13+, Command Line Tools only (no Xcode.app); tests use Swift Testing (`import Testing`), not XCTest.
- `AirSwipeCore` must not import AVFoundation, Vision or AppKit.
- Default run mode is dry-run; only `--live` may post synthetic events.
- Swipe `.right` (hand moves toward the user's right) maps to Back; `.left` maps to Forward.
- Scroll amount sign: positive = hand above neutral = scroll toward top.

## File Structure

| File | Responsibility |
|---|---|
| `Sources/AirSwipeCore/Types.swift` | `HandSample`, `SwipeDirection`, `GestureEvent`, `GestureConfig` |
| `Sources/AirSwipeCore/GestureEngine.swift` | Arm / swipe / scroll / disarm state machine |
| `Sources/AirSwipeCore/ActionMapper.swift` | `GestureEvent` → `Action`, with sub-pixel scroll accumulation |
| `Sources/AirSwipeCore/OpenPalmClassifier.swift` | Joint geometry → open palm or not |
| `Sources/airswipe/CameraSource.swift` | `AVCaptureSession` frames on a background queue |
| `Sources/airswipe/HandTracker.swift` | Vision request → `HandSample?` (mirrors x) |
| `Sources/airswipe/Sinks.swift` | `ConsoleSink` (dry run), `CGEventSink` (live) |
| `Sources/airswipe/StatusItem.swift` | Menu-bar armed indicator and Quit |
| `Sources/airswipe/main.swift` | Argument parsing and pipeline wiring |
| `Tests/AirSwipeCoreTests/*.swift` | Engine, mapper and classifier tests plus a sample-feeding rig |
